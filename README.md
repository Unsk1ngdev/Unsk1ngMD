# ⚡ Unsk1ngMD

Un asistente multifuncional para WhatsApp enfocado en alto rendimiento, dinamismo y utilidades multimedia.

**Desarrollador:** Castrodev  
**Versión:** 1.0.0

---

## 📌 Funcionalidades Destacadas

- 🎵 **Descargas Multimedia:** Procesamiento rápido de audio y video en alta calidad.
- 🧠 **Enciclopedia & Conocimiento:** Consultas de información directa con `.wiki`.
- 🛡️ **Seguridad para Grupos:** Herramientas de moderación automática para control de enlaces y mensajes repetitivos.
- 🎲 **Juegos & Dinámicas:** Modos interactivos como trivias, ruleta y acertijos.
- ⚙️ **Utilidades del Sistema:** Información detallada de números, estados y herramientas del creador.

---

## 🚀 Despliegue Rápido

1. **Clonar el proyecto:**
   ```bash
   git clone https://github.com/TU_USUARIO/Unsk1ngMD.git
   cd Unsk1ngMD
   ```

2. **Instalar dependencias:**
   ```bash
   npm install
   ```

3. **Iniciar el bot:**
   ```bash
   npm start
   ```
